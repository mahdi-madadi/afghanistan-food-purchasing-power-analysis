# Repository Metadata

## Suggested repository name

`afghanistan-food-purchasing-power-analysis`

## Short description

Reproducible analysis of wage-based wheat-flour purchasing power across 34 monitored Afghan markets, May 2020 to December 2025, using Excel, Power BI, and Python.

## About section

This portfolio project uses World Food Programme market data to calculate kilograms of low-quality wheat flour purchasable with one reported paid workday. It includes a documented data review, Power BI dashboard, Python validation workflow, research paper, and presentation.

## Recommended pinned-repository text

I built this project to demonstrate an end-to-end data-analysis workflow: raw-data audit, documented review of unusual observations, Power BI reporting, Python validation, research writing, and presentation design. The analysis is descriptive and clearly distinguishes a paid-workday affordability indicator from employment availability or household welfare.
